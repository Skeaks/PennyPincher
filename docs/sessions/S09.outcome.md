# S09 outcome, 2026-09-07

Shipped: `packages/stats` with `resolve(observations, { windowHours, now })` and
`explain(resolution)`. Exact-cents tiers, singleton noise rule at N >= 100 (never below the
floor), cap of 8, coupon-collector threshold `ceil(k·H_k·1.5)`, rare-tier guard at 3
sightings, confidence as the exact `P(all tiers seen in N)` by inclusion-exclusion. Four
`UNRESOLVED` reasons: `no_observations`, `insufficient_n`, `rare_tier_unconfirmed`,
`too_many_tiers`. 43 tests; the seeded property test records 0 floors below truth in 1,000
seeds and 4 of 783 wrong tier counts (0.5%) at N above threshold.

What the brief got wrong: "drop singletons below a documented threshold" cannot mean "always
drop singletons". At N just above the coupon threshold the rarest real tier shows up exactly
once about a third of the time, so unconditional dropping turns those cells into RESOLVED
with the floor missing, far above the 2% budget. The rule became: keep singletons under
N = 100 (they block via the rare-tier guard), drop them above the floor at N >= 100, never
drop one below the floor. The brief's `Resolution` shape also had no `n` on RESOLVED, and
`explain` needs N, so both variants carry `n`, `currency`, and `windowHours`. The "wrong
tier count" rate is measured against the exact expectation for the true shares
(`expectedDrawsToSeeAll`), which equals `k·H_k` for uniform ladders; using the uniform
formula on rare-floor ladders would have under-counted the threshold.

What was harder than expected: `needed`. Reporting only the first failing guard's shortfall
made the number creep upward ("2 more", then "5 more"). It is now the larger of the two
shortfalls, and adding it gets half of UNRESOLVED synth cells to RESOLVED in one step; the
rest need a second round because it is a point estimate from observed shares.

Not done, deliberately: `facts.isEstimate` observations are not filtered. By-weight produce
prices are estimates and may deserve their own handling; flagged for S10 or S11 to decide.
Serial correlation (`stickiness`) is S10's.
