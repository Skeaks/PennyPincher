# Schema 1.0.0

First version backed by recorded pages. Revised in S03 against the 12 scrubbed fixtures
listed in `docs/fixtures.md` (four each from Instacart, Target, Walmart; one logged-out per
retailer). Every field in `packages/schema/src/index.ts` now carries a comment naming the
fixture(s) that show it, or "context" for values only the client knows.

No stored data exists at 0.1.0 (see `0.1.0.md`), so there is nothing to migrate. The list
below is what an 0.1.0 producer (the S04 extension test fixtures were the only one) has to
change.

## Breaking

| Change | Why |
|---|---|
| `schemaVersion` literal is `"1.0.0"` | Version pin. |
| `facts.priceText` (string, required) added | The rendered price string. Every fixture sidecar carries `expected.priceText`; the Instacart qualifier "each (est.)" is not recoverable from the integer, and S05 needs to re-check a parse without the DOM. |
| `Retailer` is `instacart \| target \| walmart` | `amazon`, `safeway`, `kroger` had no fixture and no adapter. Adding one back is additive (minor bump). |
| `Fulfillment` drops `in_store` | A browser extension cannot observe an in-store price. Note `tools/scrub` keeps its own `FixtureFulfillment` vocabulary with `in_store`; follow-up to align. |
| `Surface` drops `app` | An extension cannot run inside a native app. |
| `StoreRef.retailerStoreId` is optional; at least one of `retailerStoreId` / `label` is required | Walmart pages never render the store number (only "East Windsor Supercenter"); Target and Instacart do. |
| `StoreRef.label` gains `min(1)` | An empty label no longer satisfies the "at least one" rule. |

## Additive

| Change | Why |
|---|---|
| `facts.isEstimate` (boolean, default `false`) | Instacart and Walmart mark by-weight produce "(est.)" / "Final cost by weight". The stats engine must not treat an estimate as a fixed tier. |

## Kept optional, with the reason recorded in the source

`product.upc` (no fixture renders one; S13 needs it when present), `product.brand` (Target
only), `product.sizeText` (only inside titles on every fixture), `facts.wasPrice` (no hero
shows one; Walmart's "Was $2.34" carousel tiles fix the shape), `facts.memberPrice` (no
member-gated price captured yet; S06 needs the slot), `context.zip3` (all three retailers
display a ZIP; scrubbed in fixtures, kept in sidecars), `context.cleanSession` (client-only,
set by the lever probe).

## How to read rows

Ingest (S07) stores `schemaVersion` per row and rejects anything other than `1.0.0`. There
are no 0.1.0 rows to read.
